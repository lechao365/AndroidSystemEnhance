# 树莓派5硬件认知

## 章节目标
建立实验平台认知地图，明确树莓派5能验证什么、不能验证什么，以及后续章节中硬件入口在哪里。

## 适用范围
- 以树莓派5作为Android系统开发实验平台的学习者
- 需要了解硬件边界以规划后续网络、存储等主线实验的场景
- 不涉及商业设备的硬件选型与BOM分析

## 前置条件
- 已完成 `00.1 WSL2环境搭建`，宿主开发环境可用
- 基本的计算机组成原理概念（CPU、内存、存储、总线）
- 了解Linux设备树概念（后续章节会深入，此处仅需知道其存在）

## 环境/硬件准备
- 树莓派5主板（4GB或8GB版本均可）
- 官方27W USB-C电源适配器
- Micro HDMI线与显示器
- SD卡（建议32GB+，Class 10或更高）
- USB键盘与鼠标
- 网线或USB WiFi适配器（树莓派5板载WiFi也可）
- USB转串口模块（可选，用于后续串口调试）

## 操作步骤

### 1. 认识核心硬件组成
树莓派5的核心硬件组成：

| 组件 | 型号/规格 | 与Android适配的关系 |
|------|-----------|-------------------|
| SoC | BCM2712 | 决定CPU架构、GPU驱动、设备树基础 |
| CPU | 4×Cortex-A76 @ 2.4GHz | 决定编译选项与性能基线 |
| GPU | VideoCore VII | 决定显示驱动与图形栈适配 |
| 内存 | 4GB或8GB LPDDR4X | 决定系统可用内存与多任务能力 |
| 存储 | Micro SD卡槽 + PCIe NVMe（经HAT） | 决定启动介质与存储性能上限 |
| 网络 | 千兆以太网 + WiFi 5 + BT 5.0 | 决定网络实验入口 |
| USB | 2×USB 3.0 + 2×USB 2.0 | 决定外设扩展方式 |
| 显示 | 2×Micro HDMI 4Kp60 | 决定显示输出方式 |

执行要求：
- 对照实物确认上述组件位置
- 记录自己手中树莓派5的内存版本与外设配置

### 2. 连接最小实验环境
按以下顺序连接：

1. 将SD卡插入卡槽
2. 连接Micro HDMI线到显示器
3. 连接USB键盘与鼠标
4. 连接网线（或确认WiFi可用）
5. 最后连接电源线

执行要求：
- 电源必须最后连接，避免带电插拔其他接口
- 确认所有物理连接牢固，无松动
- 首次上电后观察红色电源指示灯与绿色活动指示灯

### 3. 识别启动、显示、网络、存储四类关键接口

**启动接口**：SD卡槽是主启动介质，PCIe NVMe需额外配置方可启动
**显示接口**：两个Micro HDMI口，靠近电源的为HDMI0（主显示）
**网络接口**：以太网口靠近USB侧，WiFi/蓝牙为板载芯片
**存储扩展**：USB 3.0可接外置存储，PCIe（经HAT）可接NVMe SSD

执行要求：
- 能在实物上指出这四类接口的物理位置
- 知道每个接口在后续Android实验中的用途

### 4. 标记本平台可验证与不可验证边界

| 维度 | 树莓派5可验证 | 需迁移到商业设备理解 |
|------|-------------|-------------------|
| 启动流程 | SD卡启动链、Bootloader加载 | 安全启动链、AVB验证、AB分区 |
| 显示输出 | HDMI输出、基础GUI渲染 | DSI/CSI接口、多屏同显异显 |
| 网络通信 | WiFi/以太网基础连通 | 蜂窝网络、运营商认证、IMS |
| 存储访问 | SD卡/USB存储读写 | UFS、eMMC、动态分区、FBE加密 |
| 外设扩展 | USB设备热插拔 | I2S/PCM音频、NFC、指纹 |
| 电源管理 | 基础供电与散热 | 电池管理、充电协议、低功耗模式 |

执行要求：
- 明确哪些实验可以在树莓派5上直接完成
- 对于不可验证项，知道需要迁移到什么类型的商业设备

### 5. 为后续网络与存储主线建立硬件映射

| 后续主线 | 树莓派5硬件入口 | 对应商业设备入口 |
|---------|---------------|----------------|
| 网络子系统 | 板载WiFi + 以太网 | WiFi/BT芯片 + 蜂窝Modem |
| 存储子系统 | SD卡 + USB存储 | UFS/eMMC + 动态分区 |
| USB子系统 | 4个USB口 | Type-C DRP + USB Hub |
| 显示子系统 | Micro HDMI × 2 | DSI + HDMI + DP |

执行要求：
- 知道后续每条主线在树莓派5上的硬件入口
- 知道对应商业设备的差异点

## 验证方法
- 能画出树莓派5最小实验连接图（电源→主板→SD卡→HDMI→显示器→键鼠→网络）
- 能说明启动介质（SD卡）、显示输出（Micro HDMI）、网络入口（WiFi/以太网）、外设扩展（USB）四种关键接口
- 能说清哪些实验适合在树莓派5验证（基础启动、显示、网络连通、USB外设），哪些需要迁移到商业设备理解（安全启动、蜂窝网络、UFS存储、电池管理）

## 常见问题与排查
- **上电无显示**：先确认HDMI线连接到HDMI0口，检查显示器输入源是否切换正确，再确认SD卡是否已写入系统镜像
- **绿色指示灯不闪烁**：说明SD卡未被读取，检查SD卡是否插入到位、是否已写入可启动镜像
- **网络不可用**：先确认网线连接或WiFi配置，树莓派5板载WiFi需驱动支持，部分Android镜像可能未集成WiFi驱动
- **USB设备不识别**：确认连接到USB 3.0口（蓝色），部分设备需要额外供电
- **散热不足导致降频**：树莓派5高负载时温度较高，建议加装散热片或风扇，否则CPU会自动降频
