# 00-环境准备

## 章节目标
建立 Android 系统开发的最小可运行闭环，确保后续所有章节都能落地验证，并完成从宿主环境、源码获取、系统构建、镜像部署到基础调试的首轮打通。

## 本章使用方式
1. 按 `00.1` 到 `00.6` 的顺序执行，不建议跳章。
2. 每一节至少完整执行一次步骤，确认验证通过，并记录过程中遇到的问题与处理结果。
3. 如果当前环境、硬件或部署介质不满足要求，先记录阻塞点和影响范围，不要直接跳到后续主线章节。

## 建议学习顺序
1. `00.1 WSL2环境搭建`
2. `00.2 树莓派5硬件认知`
3. `00.3 Android系统构建`
4. `00.4 刷机与部署`
5. `00.5 增量开发与上板调试`
6. `00.6 开发调试环境`
7. `00.7 远程访问`

## 本章统一验收标准
- 能说明宿主环境、源码目录、构建产物、部署介质之间的关系。
- 能独立完成一次全量构建与首次启动。
- 能完成至少一次最小增量修改与验证。
- 能说清常用日志、ADB、串口三类入口的适用场景。

## 与后续章节的衔接
- `00` 章完成后进入 `01-构建系统`，重点理解 Android 构建原理、产物组织方式与常见编译入口。
- 在进入网络和存储等后续主线前，至少完成 `00.3` 到 `00.6` 的一次完整闭环，确保已经具备构建、部署、修改、验证和调试的基础能力。

## 求职映射

- **对应岗位**：所有 Android 平台岗位的基础前提，尤其适用于系统开发、平台移植、设备定制与 BSP 联调岗位
- **面试高频点**：宿主环境要求、源码目录结构、全量编译流程、刷机部署方式、增量调试闭环
- **能力证明点**：能够独立完成环境搭建、系统构建、首次启动、最小修改验证与基础调试入口接入
- **树莓派可验证边界**：完整可验证
- **迁移差异**：商业设备常见 fastboot、USB 下载或串口辅助刷机，树莓派以 SD 卡部署为主，但核心流程仍可迁移到其他 Android 设备
