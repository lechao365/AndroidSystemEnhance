## 修复内容
- **KRN-004**（lciod_usbd.c）：O_NONBLOCK read 的 empty/shutdown 检查顺序对齐阻塞路径 drain 语义——原 shutdown 先判会丢弃非空 ring 尾部事件（EPOLLIN|EPOLLHUP 后首次 read 得 0 误判 EOF）；现空环才按 shutdown 分流 0/-EAGAIN。
- **KRN-007**（lcview_main.c）：lcview read 支持 O_NONBLOCK——空环返回 -EAGAIN（原无 file 上下文判定，一律阻塞）。竞态窗口无害（EAGAIN 重试语义）。
- **KRN-016**（lciod_usbd-stats.c）：8 个 trace helper 的 builder add 返回值聚合（rc |=），任一字段写入失败整体 cancel，杜绝"头计数与数据不一致"的残缺记录进入用户态解析。
- **KRN-015**（lcview_builder.c）：field_count（uint8_t）达 255 拒绝写入（3 处：write_field/add_str/add_binary），防回绕导致 commit 头与 TLV 数据不一致。
- **KRN-014**（lcview_ring.c/lcview_builder.c）：ring full 与 kmalloc failed 日志改 pr_err_ratelimited，防 I/O 洪水日志风暴。
- **KRN-018**（lcview_main.c）：GET_OVERRUN 改 atomic_xchg 原子读清（消除 read→copy→set 窗口丢失并发增量）；ring_size_kb module_param 0644→0444（仅加载时可设）。
